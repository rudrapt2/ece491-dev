## Steps to get working:

1. Compile with "make zork.o"
2. Copy zork.o into same directory as trek.o in FA24MP2CP1
3. Replace FA24MP2CP1 kernel.ld with kernel.ld_mp2_cp1
4. Replace FA24MP2CP1 Makefile with Makefile_mp2_cp1
5. Make cp1.elf and run by calling zork_main_fr (NOT zork_main) in FA24MP2CP1 main
