# ECE 391 MP3 Docs

## Overview

This is the student handout documentation for MP3. We use LaTeX to generate the PDF file.

## How to generate the PDF file

1. Install `texlive` on your system. For Ubuntu, you can run `sudo apt-get install texlive-full`.
2. Run `make` in the `dox/mp3-handout` directory. Note: you may need to run `make` twice to properly generate the table of contents.
3. The PDF file will be generated as `mp3.pdf`.
